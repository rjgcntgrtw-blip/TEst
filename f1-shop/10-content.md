# Карточки товаров: фото и описания

## Как добавляем товар

1. **Ты** находишь товар на AliExpress и присылаешь:
   - ссылку на товар и запасного продавца;
   - цену продажи;
   - для одежды — какие цвета и размеры берём.
2. **Фото:** главное фото 3/4 спереди, 3–6 других ракурсов и фото коробки.
   Когда доступ к AliExpress будет открыт, я скачаю фото сам по ссылке. До этого — загружай их в
   `site/content/products/<slug>/raw/` на GitHub (Add file → Upload files) или присылай в чат.
3. **Я:**
   - создаю папку товара и пишу описание по шаблону ниже;
   - прогоняю фото через обработку;
   - проверяю карточку на сайте и коммичу.
4. **Ты** проверяешь пункты из поля `verify` (что уточнить у продавца) и ставишь `"status": "published"`.

## Фото

### Главное правило — только реальные фото товара

Фото — продавца или твои собственные. Я убираю фон, ставлю все товары в одинаковый кадр
(«на один пол», одинаковый масштаб), добавляю мягкую тень и собираю кадр «модель + коробка».
**Не дорисовываю детали, не меняю цвета и не генерирую товар нейросетью.**

Почему так:
- Если товар не соответствует фото и описанию, покупатель вправе его вернуть (ЗоЗПП, ст. 10 и 12),
  а в дропшиппинге каждый возврат — чистый убыток.
- Нейросеть «придумывает» детали: ливрею, наклейки, форму антикрыла. Коллекционеры это замечают сразу.
- Higgsfield и другие генераторы используем только для атмосферы: интро, фоны, баннеры.
  Никогда — вместо фото товара.

### Какие фото нужны

| Фото | Файл | Требования |
|---|---|---|
| Главное | `main.jpg` | **3/4 спереди — лицом к покупателю.** У всех моделей нос в одну сторону (вправо). Не зеркалить — надписи ливреи отразятся |
| Ракурсы | `01.jpg`, `02.jpg` … | сбоку, сзади, сверху, крупно кокпит и антикрылья |
| Вид сверху, детали | `03-center.jpg` | суффикс `-center`: ставится по центру кадра, а не «на пол» |
| Коробка | `box.jpg` | заводская коробка, в которой модель приедет. На сайте — пометка «В этой коробке приедет» и кадр «модель + коробка» |
| Без обработки | `04-keep.jpg` | суффикс `-keep`: фон не удаляется (вещь на человеке, крупный план ткани) |

- Разрешение — от 1000 px по длинной стороне.
- Без водяных знаков, коллажей и текста поверх. Если у продавца таких фото нет — лучше снять образец самому.
- Фото продавцов — чужой контент. Для хитов продаж лучше своя съёмка образцов: это ещё и контент для Telegram.
- Своей брендированной коробки в дропшиппинге не будет: модель едет в заводской упаковке продавца.
  Поэтому показываем честно именно её.

### Обработка

```bash
cd site
pip install -r tools/images/requirements.txt   # один раз
npm run images -- <slug>                        # фото одного товара
npm run images -- <slug> --align center         # одежда разложенная — по центру кадра
npm run catalog                                 # обновить каталог сайта
```

На выходе в `site/public/products/<slug>/` лежат `main.webp`, `thumb.webp`, ракурсы, `box.webp`
и `with-box.webp`. Сейчас в `raw/` лежат 3D-макеты вместо фото — на них проверена вся цепочка.

## Папка товара

```
site/content/products/<slug>/
  product.json    данные и описание — попадают на сайт
  supplier.json   ссылки на AliExpress, закупочная цена, соответствие размеров — на сайт НЕ попадают
  raw/            исходные фото
```

`supplier.json`:

```json
{
  "aliexpress": "https://aliexpress.ru/item/…",
  "backup": "https://aliexpress.ru/item/…",
  "cost": 1290,
  "sizeMap": { "M": "XL", "L": "XXL" },
  "notes": "просить не вкладывать инвойс"
}
```

`sizeMap` — какой размер продавца заказывать под наш размер (азиатские размеры маломерят).
Репозиторий с `supplier.json` должен оставаться **приватным**.

## Шаблон описания: модель

| Поле | Правило | Пример (Red Bull RB19, 1:43) |
|---|---|---|
| Лид | 1–2 предложения: чем знаменит болид или сезон и кто пилот. Факт должен проверяться | «Болид, который выиграл 21 гонку из 22…» |
| Абзацы | масштаб → реальная длина в см, материал, что видно на модели. Лицензия — только если она есть на коробке или в карточке | «Литая модель Bburago в масштабе 1:43 — около 13 см в длину…» |
| Что в коробке | только то, что реально в комплекте | модель; заводская коробка |
| Характеристики | масштаб, длина, материал, производитель, лицензия, возраст (14+), упаковка, страна производства | — |
| SEO-заголовок | до 60 символов: «Модель {болид} {пилот} {масштаб} {бренд}» | «Модель Red Bull RB19 Ферстаппен 1:43 Bburago» |
| SEO-описание | до 160 символов: что, сезон, масштаб, лицензия, доставка | — |

Длина модели = длина настоящего болида / масштаб. Современный болид — около 5,6 м:
1:43 ≈ 13 см, 1:18 ≈ 31 см, 1:8 ≈ 70 см.

Тон: на «ты», коротко, по делу. Нельзя:
- «уникальный», «лучший», «премиальный» без оснований;
- машинный перевод из карточки продавца;
- «оригинал» и «лицензия» без подтверждения;
- обещания, которых нет в карточке продавца (открывающиеся детали, подставка, бокс).

## Одежда

**Ассортимент:**
- **футболки** — основа;
- **кофты** (худи и свитшоты) — редко, к осени и зиме;
- **кепки**.

Только одежда в стиле официальной командной формы: реплики с пометкой «Реплика» или лицензия, если продавец её подтверждает.
Фанатских дизайнов нет (см. [02-legal.md](02-legal.md#товарные-знаки)).

**Размеры** — главный источник возвратов:
- Азиатские размеры на AliExpress обычно маломерят. На сайте показываем **свою таблицу в сантиметрах**
  (ширина груди, длина, рост), а не буквы продавца.
- Соответствие «наш размер → размер продавца» хранится в `supplier.json` → `sizeMap`.
- В описании — как выбрать размер: «измерь свою футболку, разложив её ровно».
- Резерв на возвраты по одежде — 10 %, а не 5 %.

**Фото:**
- Футболки и кофты — раскладка спереди и сзади на прозрачном фоне (`--align center`).
- Фото на человеке — с суффиксом `-keep`.
- Крупно: принт и ткань.
- Кепки — 3/4 спереди, как болиды.

**Описание одежды:**
- лид — чья это форма и какого сезона;
- состав и плотность ткани;
- крой, способ печати и где она;
- уход;
- таблица размеров. У кепки — обхват головы и тип застёжки.

**На сайте:**
- выбор цвета и размера;
- пока размер не выбран, кнопка показывает «Выбери размер»;
- «Таблица размеров» открывается в боковой панели.
