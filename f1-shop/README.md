# TMFF — магазин моделей и мерча для фанатов F1: рабочий план

Дропшиппинг: покупатель оплачивает заказ на нашем сайте, мы заказываем товар на AliExpress
с доставкой сразу на адрес покупателя. Основной ассортимент — готовые масштабные модели болидов,
дополнительно конструкторы (включая LEGO) и одежда/мерч. Продвижение — Telegram и короткие видео, продажи — через сайт.

> Состояние на сентябрь 2026. Цифры по тарифам и ценам взяты из открытых источников
> и должны быть перепроверены перед подписанием договоров (ссылки — в каждом файле).

## Инструменты

| Что | Где | Статус |
|---|---|---|
| **UI UX Pro Max** — база стилей, палитр и правил UX | `.claude/skills/ui-ux-pro-max/` | ✅ установлен, подхватывается автоматически в сессиях с этим репозиторием |
| **Motion** (framer-motion) — анимации | зависимость в `site/package.json` | ✅ установлен |
| **21st.dev** — готовые анимированные компоненты | настройка в `.mcp.json` | ⏳ нужен твой ключ, шаги ниже |
| **Прототип главной** | `site/` | ✅ запуск: `cd site && npm install && npm run dev` → http://localhost:3000 |

Как включить 21st.dev:
1. Получить бесплатный ключ на https://21st.dev/mcp.
2. Открыть настройки облачного окружения: в приложении создать новую сессию, в поле ввода выбрать окружение,
   навести на него и нажать шестерёнку.
3. В разделе **API credentials** нажать **Add credential**:
   - хост — `21st.dev`;
   - в **Custom headers** имя заголовка — `x-api-key`;
   - префикс `Bearer` стереть;
   - в значение вставить ключ.

   Ключ хранится вне сессии, и его никто не видит. **Не класть ключ в Environment variables и не присылать в чат.**
4. Открыть новую сессию — коннектор подключится сам.

Сеть: у окружения стоит **Network access → Full**, поэтому AliExpress, картинки товаров и 21st.dev доступны.

## Дорожная карта (отмечай галочки по ходу)

### Этап 0. Проверка ниши — 1–2 недели
- [ ] Выбрать 10–15 стартовых товаров — стартовый набор уже подобран в [11-aliexpress-research.md](11-aliexpress-research.md)
- [ ] Заказать себе образцы 3–5 ключевых позиций: проверить качество, упаковку, срок доставки, наличие чека/цены в посылке
- [ ] Записать фактический срок доставки по каждому продавцу (это обещание покупателю)
- [x] Название: **TMFF**
- [ ] Выбрать расшифровку и слоган, проверить название в ФИПС, домены и соцсети ([07-brand.md](07-brand.md))
- [ ] Завести Telegram-канал, начать публиковать контент ещё до запуска сайта

### Этап 1. Юридическое оформление — 1–2 недели
- [ ] Зарегистрировать ИП, выбрать УСН «Доходы» 6 % (самозанятость **не подходит** — перепродажа запрещена)
- [ ] Открыть расчётный счёт
- [ ] Подать уведомление в Роскомнадзор об обработке персональных данных — **до** запуска сайта
- [ ] Подготовить оферту, политику конфиденциальности, отдельное согласие на обработку ПДн, правила возврата
- [ ] Показать схему бухгалтеру/юристу: дропшиппинг из-за рубежа, маркировка, возвраты ([02-legal.md](02-legal.md))

### Этап 2. Приём платежей — ~1 неделя
- [ ] Подать заявку в ЮKassa с сервисом «Чеки от ЮKassa» (основной вариант)
- [ ] Подать заявку в Робокассу (запасной вариант), сравнить предложенные ставки
- [ ] Настроить два чека: «предоплата 100 %» при оплате и «полный расчёт» при получении
- [ ] Провести тестовые платежи картой и через СБП

### Этап 3. Сайт — 2–3 недели
- [ ] Прислать референсы для сайта и анимации, выбрать стиль ([07-brand.md](07-brand.md))
- [ ] Сгенерировать в Higgsfield видео для главной, болид для интро и фоны команд — задание в [higgsfield-task.md](higgsfield-task.md)
- [ ] Прислать реквизиты ([04-website.md](04-website.md#что-нужно-от-тебя))
- [ ] Зарегистрировать сервисы из [08-services.md](08-services.md)
- [ ] Найти товары и прислать ссылки, фото и цены — описания и обработку фото делаю я ([10-content.md](10-content.md))
- [ ] Купить домен `.ru`, арендовать VPS в России
- [ ] Собрать MVP: каталог (одежда/мерч → модели → команды, фильтры), карточки, корзина, оплата, уведомления в Telegram
- [ ] Заполнить каталог, юридические страницы, FAQ по срокам доставки и возвратам
- [ ] Подключить Яндекс Метрику, Вебмастер, проверить скорость и мобильную версию

### Этап 4. Процесс обработки заказа
- [ ] Отработать цикл на 2–3 тестовых заказах (схема — в [01-business-model.md](01-business-model.md#как-проходит-заказ))
- [ ] Шаблоны сообщений покупателю: заказ принят → отправлен (трек) → доставлен
- [ ] Таблица заказов: номер, товар, ссылка Ali, номер заказа Ali, трек, статус, сумма, маржа
- [ ] Порядок действий при возврате, браке и потере посылки

### Этап 5. Запуск и продвижение
- [ ] Контент-план на первый месяц ([06-marketing.md](06-marketing.md))
- [ ] Вести рекламу своего магазина только с маркировкой (erid) через ОРД
- [ ] Разместить топовые позиции на Авито как дополнительный канал

### Этап 6. Рост (когда будут стабильные продажи)
- [ ] Держать хиты продаж на своём складе в России, чтобы доставлять за 1–3 дня
  (меняются обязанности по маркировке и сертификации — сначала проконсультироваться)
- [ ] Искать поставщиков напрямую и через 1688 для лучших закупочных цен
- [ ] Рассмотреть лицензированный мерч и официальных дистрибьюторов
