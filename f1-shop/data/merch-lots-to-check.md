# Задание: мерч в стиле командной формы на aliexpress.ru

Выполняет Claude в Chrome на компьютере владельца. Облачной сессии aliexpress.ru показывает капчу.
Если капча появится у тебя — попроси пользователя пройти её вручную и продолжай.

## 1. Лоты от владельца

Открой каждую ссылку и запиши **каждый вариант** (цвет, пилот, размер — если цена от размера зависит).

- https://aliexpress.ru/item/1_672792682.html?sku_id=5000003438087973
- https://aliexpress.ru/item/1_674952136.html?sku_id=5000003444200901

Новые ссылки владелец будет дописывать сюда же.

## 2. Поиск на aliexpress.ru

Нужны **футболки и кепки Mercedes, Ferrari и Red Bull сезонов 2020–2026 в стиле официальной формы**:
цвета команды, логотипы партнёров, номер пилота. Фанатские принты, винтаж, мемы и печать на заказ не нужны.

Запросы (по каждому — первые 2 страницы выдачи, сортировка по количеству заказов):

- футболка mercedes f1 / футболка petronas / футболка хэмилтон 44 / футболка рассел 63 / футболка боттас 77
- футболка ferrari f1 / футболка scuderia / футболка леклер 16 / футболка сайнс 55 ferrari
- футболка red bull racing / футболка oracle red bull / футболка ферстаппен / футболка перес 11
- кепка mercedes f1 / кепка ferrari f1 / кепка red bull racing / кепка хэмилтон / кепка ферстаппен / кепка леклер

Бери лоты от 20 заказов и с оценкой от 4.5 (или без оценки, если заказов много).

## Результат

Сохрани в `f1-shop/data/merch-variants.csv` (UTF-8, разделитель — запятая):

```
lot_id,ссылка,команда,вещь,пилот_номер,сезон,вариант,цена_руб,заказов,рейтинг,фото_url,заметки
```

- `вещь` — футболка / поло / кепка / худи.
- `сезон` — год формы, если понятно по дизайну или названию; иначе пусто.
- `фото_url` — ссылка на главное фото варианта в полном размере (без суффикса `_220x220.jpg`).
- `заметки` — например, «цена зависит от размера», «есть только S–L».

Потом закоммить файл и запушь в ветку `claude/test-h284oh`.
