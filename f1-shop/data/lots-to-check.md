# Задание: собрать варианты лотов AliExpress

Выполняет Claude Code на компьютере владельца, в его браузере Chrome (`claude --chrome`).
Облачная сессия сделать это не может: страницы лотов для неё закрыты капчей.

## Что сделать

Открой по очереди каждую ссылку ниже в Chrome. Если появится капча, остановись и попроси пользователя
пройти её вручную, потом продолжай. На каждой странице:

1. Найди блок выбора варианта (модель / цвет / комплектация).
2. Нажимай на каждый вариант по очереди и записывай название варианта и цену, которая показывается при выборе.
3. Запиши рейтинг лота и число заказов («купили»).
4. У реплик конструкторов отдельно проверь, есть ли вариант «с коробкой» / «with box», и найди в отзывах
   фото коробки: есть ли на ней логотип LEGO, какого качества печать.

Результат сохрани в `f1-shop/data/lot-variants.csv` (UTF-8, разделитель — запятая) с колонками:

```
lot_id,раздел,вариант,машина,пилот_номер,год,масштаб,цена_руб,с_коробкой,рейтинг,заказов,заметки
```

- `машина` — нормализованное название болида: `Ferrari SF-25`, `Red Bull RB21`, `Mercedes W16`, `McLaren MCL39` и т. п.
- `пилот_номер` — например `Leclerc #16`. Если нет — пусто.
- `с_коробкой` — `да` / `нет` / `не указано`.
- Цены — в рублях, как показывает aliexpress.ru.

Потом закоммить файл и запушь в ветку `claude/test-h284oh`.
