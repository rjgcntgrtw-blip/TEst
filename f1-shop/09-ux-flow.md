# Главная страница: сценарий и анимации

Референсы, которые прислал:
- **Открывающая анимация** — постер Deadpool («CINE DAILY»): огромные узкие буквы выплывают
  из темноты, персонаж стоит **перед** буквами, за ним красный круг, потом появляются меню и мелкие блоки.
- **Витрина** — сайт энергетика «CIAO»: банки стоят дугой под прожектором, центральная — на
  светящемся постаменте. При выборе соседние банки разъезжаются, выбранная остаётся в центре,
  фон заливается её цветом, слева появляется текст, справа — точки-шаги, банка поворачивается при прокрутке.

## Сценарий по экранам

```
┌──────────────────────────────────────────────┐
│ 1. ИНТРО (первый экран)                      │
│    TMFF огромными буквами, болид перед ними, │
│    за болидом — красный «стартовый огонь»,   │
│    огонь гаснет → «lights out» → меню,       │
│    подпись «Листай вниз»                     │
├──────────────────────────────────────────────┤
│ 2. ВИТРИНА                                   │
│  [Одежда] [Модели] [Команда ▾] [Год ▾]       │ ← одна строка
│  (ничего не выбрано → «Популярное сейчас»)   │
│                                              │
│      ◜  ▫   ▫   ▣   ▫   ▫  ◝                 │ ← товары дугой, прожектор сверху
│               ═══                            │ ← постамент под центральным
│          ‹   Название · цена   ›             │
├──────────────────────────────────────────────┤
│ 3. КАРТОЧКА ТОВАРА (та же сцена)             │
│  ▫▫▣▫▫  ← мини-лента сверху, «← К витрине»   │
│                                              │
│  Инфо о товаре   [ФОТО ТОВАРА]      ● Сезон  │
│  цена, масштаб,   ‹ свайп ›         ○ Пилот  │
│  доставка,        • • • •           ○ Момент │
│  [В корзину]                                 │
│  фон — белый                                 │
└──────────────────────────────────────────────┘
```

### 1. Интро
- Чёрный экран → буквы **TMFF** проявляются из тёмно-серого в белый, по одной.
- За буквами загорается красный круг — **стартовый огонь**. Болид выезжает из темноты
  перед буквами (размытие → резкость).
- Огонь гаснет — «lights out» — и появляются меню, фамилии пилотов строкой сверху
  (как имена актёров на постере), вертикальная подпись сезона справа и кнопка «Смотреть витрину».
- Длительность ~2,5 с, играет один раз. Если в системе включено «уменьшить движение» — сразу финальный кадр.
- В прототипе болид нарисован заглушкой. В финале — вырезанное фото или рендер из Higgsfield
  (картинка 3/4 спереди на прозрачном фоне, без логотипов).

### 2. Витрина
- Панель фильтров в одну строку: **Одежда · Модели · Команда · Год**.
  - Ничего не выбрано — показываем популярное сейчас (сортировка по популярности).
  - Выбрана «Модели» — появляется уточнение: *Готовые / Конструкторы*.
  - Выбрана «Одежда» — уточнение: *Футболки / Кофты / Кепки*.
  - «Команда» и «Год» — выпадающие списки, показывают только то, что есть в наличии.
- **Фон витрины:** по умолчанию тёмная студия с прожектором. Если гость выбрал **команду**,
  фон плавно меняется на фон этой команды: её цвета, градиент и крупное название команды на заднем плане.
- Товары стоят **дугой в перспективе**, центральный — крупнее, под прожектором и на постаменте.
- Листать: стрелки ‹ ›, клавиши ← →, свайп или перетаскивание мышью.
- **Клик по центральному или соседнему (±1)** товару — открывает карточку.
  Клик по дальнему — сначала подкручивает к нему витрину.
- **Прокрутка вниз** открывает карточку того товара, что стоит в центре.

### 3. Карточка товара
- Соседние товары разъезжаются в стороны и гаснут, **выбранный остаётся в центре** и растёт,
  фон плавно становится **белым**, на белом фоне фото товаров смотрятся как в студии.
- У товара несколько фотографий, они листаются **обычным свайпом**, стрелками или точками под фото.
  3D-модели и вращения, как у банки в референсе, нет: для одежды это не работает, а фото честнее
  показывают товар.
- Слева — информация: название, цена, масштаб, производитель, лицензия, срок доставки, «В корзину».
- Справа — **история сезона** в три шага, шаги переключаются прокруткой
  (точки-индикаторы как в референсе): что происходило с командой, с пилотом, ключевой момент.
- Сверху — **мини-лента витрины**: уменьшенная копия той же ленты, выбранный товар подсвечен.
  Листать её нельзя (как ты и хотел). Вся лента — одна кнопка «← К витрине», которая возвращает
  назад. Без этого мини-лента выглядит кликабельной, но ничего не делает — это путает.
- Адрес страницы меняется на `?p=название-товара` — карточкой можно поделиться в Telegram.

### 4. Поиск, корзина, оформление

- **Поиск** — лупа в шапке: полноэкранный слой, ищет по названию, пилоту, команде, году и масштабу.
  Enter или клик открывает карточку товара сразу, без прокрутки витрины.
- **Корзина** — выезжает справа: количество, удаление, сумма, срок доставки. Хранится в браузере, переживает перезагрузку.
  После «В корзину» — всплывашка с кнопкой «Корзина», иконка в шапке подпрыгивает.
- **Оформление** — имя, телефон, email для чека, город, адрес или пункт выдачи, комментарий и согласие с офертой
  и обработкой ПДн. До подключения ЮKassa последний шаг предлагает скопировать заказ и написать в Telegram.

### 5. Адреса и превью

- У каждого товара своя страница `/p/<slug>` с заголовком и описанием для поисковиков. Она открывает витрину сразу
  на карточке. Когда покупатель открывает карточку на главной, адрес меняется на `/p/<slug>` — им можно поделиться.
- Превью ссылки в Telegram и соцсетях рисуется кодом (TMFF, огни, слоган). `sitemap.xml` и `robots.txt` генерируются
  при сборке; адрес сайта задаётся переменной `NEXT_PUBLIC_SITE_URL`.
- Раздел «Покупателям» — `/info`: доставка и оплата, возврат, оферта, политика ПДн, контакты.
  Реквизиты ИП в квадратных скобках — заполнить.

### 6. Интро: один раз за визит

- Полное интро — только при первом заходе за сессию. Повторный заход и прямые ссылки на товар — сразу финальный кадр.
- Клик, прокрутка или клавиша во время интро — пропуск. «Уменьшить движение» в системе — без анимации.
- Файлы из Higgsfield ([higgsfield-task.md](higgsfield-task.md)) подхватываются автоматически: видео за буквами,
  болид вместо 3D-заглушки, фоны команд вместо градиента.

## Компьютер и телефон

| | Компьютер | Телефон |
|---|---|---|
| Интро | буквы на всю ширину, болид в центре | то же, буквы и болид крупнее относительно экрана |
| Фильтры | одна строка по центру | одна строка с горизонтальной прокруткой |
| Витрина | видно 7–9 товаров на дуге | видно центральный и половинки соседей, свайп |
| Карточка | белый фон, три колонки: инфо · фото со свайпом · история сезона | белый фон, фото со свайпом сверху, под ним инфо и история |

## Производительность и что урезаем, если не потянет

- Анимируются только `transform` и `opacity` — это дёшево для видеокарты.
- На дуге одновременно отрисовывается не больше 9 товаров, остальные не создаются.
- Фото товаров — WebP/AVIF нужного размера, загрузка по мере приближения к центру.
- Порядок урезания, если на слабых телефонах будет тормозить:
  1. отключить размытие (blur) в интро и на фоне;
  2. на телефоне заменить дугу в перспективе на плоскую ленту;
  3. убрать связку карточки с прокруткой — открывать карточку кликом без «сцены».

## Технологии

- **Next.js + React + TypeScript** — нужен для сложной интерактивной витрины и для отдельных
  страниц товаров под поиск. Заменяет Astro из первой версии плана.
- **Motion** (бывший framer-motion) — анимации интро, витрины и карточки.
- **Tailwind CSS** — стили.
- **UI UX Pro Max** — навык с базой стилей и правил UX, установлен в `.claude/skills/`.
- **21st.dev** — готовые анимированные компоненты. Подключение описано в [README](README.md#инструменты).
