# Товары

Одна папка — один товар: `product.json` (данные и описание для сайта), `supplier.json`
(поставщик и закупка — на сайт не попадает) и `raw/` (исходные фото).

Как добавлять товары, требования к фото и шаблоны описаний — в
[`f1-shop/10-content.md`](../../../f1-shop/10-content.md).

Сейчас все товары — примеры (`"status": "placeholder"`), а в `raw/` лежат 3D-макеты вместо фото.
